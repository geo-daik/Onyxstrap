# Account Manager (temporarily removed)

The Account Manager (saved accounts, one-click switching, per-account FastFlag sets) is **temporarily removed** as of v1.0.5 while its session-switching mechanism is reworked.

It will return in a future release. Everything else - FastFlags, presets, mods, the Onyx loading screen - is unaffected.

If you previously saved accounts, their encrypted data was local-only and is no longer read by Onyxstrap.
