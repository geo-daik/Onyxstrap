# Onyxstrap Wiki

Welcome to the Onyxstrap wiki — help and documentation for Onyxstrap, an alternative bootstrapper for Roblox with a built-in account manager.

> Onyxstrap is based on [Bloxstrap](https://github.com/bloxstraplabs/bloxstrap) by pizzaboxer (MIT). It is a community project and is not affiliated with Roblox Corporation.

## Pages

- **[Installing Onyxstrap](Installing-Onyxstrap)** — installing, updating, uninstalling, and what Onyxstrap changes on your PC
- **[Account Manager](Account-Manager)** — saving accounts, switching, per-account FastFlags and presets, and how account switching works
- **[Engine Settings (FastFlags)](Engine-Settings-FastFlags)** — the FastFlag editor, per-account flag sets, and presets
- **[Mods & Customization](Mods-and-Customization)** — file mods, bootstrapper styles (including the Onyx cutscene), icons, and the game window rebrand
- **[Troubleshooting](Troubleshooting)** — common problems and how to read Onyxstrap's logs
- **[Security & Privacy](Security-and-Privacy)** — how your session tokens are stored and what Onyxstrap sends over the network

## Quick facts

| | |
|---|---|
| Install location | `%LOCALAPPDATA%\Onyxstrap` |
| Config files | `Settings.json`, `Accounts.json`, `State.json` in the install location |
| FastFlags | `Modifications\ClientSettings\ClientAppSettings.json` |
| Logs | `Logs\` in the install location |
| Command line | `Onyxstrap.exe -menu`, `-player`, `-studio`, `-quiet`, `-uninstall` |
